# Basic Chatbot

A simple rule-based chatbot developed using Python. The chatbot interacts with users through predefined responses and performs basic tasks such as displaying the current date and time and performing arithmetic calculations.

## Features

- Responds to basic greetings
- Answers predefined questions
- Displays the current date
- Displays the current time
- Performs basic arithmetic calculations
- Handles invalid calculator inputs
- Provides a help menu with available commands
- Runs continuously until the user chooses to exit

## Technologies Used

- Python 3
- Python `datetime` module

## Concepts Used

- Functions
- Loops
- Conditional statements (`if-elif-else`)
- User input and output
- Exception handling
- Python modules

## How to Run

1. Make sure Python is installed on your system.

2. Clone the repository or download the project files.

3. Open the project directory.

4. Run the Python file:

```bash
python chatbot.py
